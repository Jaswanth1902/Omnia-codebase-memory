# Contributing

Thank you for your interest in contributing! We welcome all issues, discussions, and pull requests.

## How to Contribute

1. **Open an Issue**: For non-trivial changes, open an issue first to discuss the architecture or feature proposal.
2. **Fork & Branch**: Create a feature branch (`git checkout -b feature/amazing-feature`).
3. **Commit Cleanly**: Follow conventional commits (`feat: ...`, `fix: ...`, `docs: ...`).
4. **Test**: Ensure all existing tests pass before submitting.
5. **Open a Pull Request**: Provide a clear description of what changed.

## Community Code of Conduct
Please be welcoming, respectful, and constructive in all GitHub discussions, reviews, and issues.
