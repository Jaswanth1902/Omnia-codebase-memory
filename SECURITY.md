# Security Policy

## Supported Versions
We release security updates and bug fixes for the latest version on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of our open-source tools seriously. If you discover a security vulnerability or sensitive information exposure, please report it responsibly.

### How to Report
- **Email**: Contact the maintainer directly at [jaswanthreddy1537@gmail.com](mailto:jaswanthreddy1537@gmail.com) with the subject `[SECURITY ISSUE] - <Repository Name>`.
- **Do NOT**: Please do not file public issues or post publicly about the vulnerability until it has been investigated and remediated.

### What to Include
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step instructions or minimal code to reproduce the issue.
3. Remediation suggestions if available.

### Response Commitment
We will acknowledge receipt of your report within 48 hours and work diligently to validate, patch, and release a fix.
